# [Project name TBD]

Sensor fusion for messy drone data. Allied sensors produce noisy, cluttered detections; we fuse them into tracks,
estimate where each drone likely launched from and where the launch team will likely go next, show which friendly routes
are exposed to being traced back to their origin, and let a human approve a surveillance drone to go look.
An AI layer explains the picture in plain language. A human approves every action.

Built at c0mpiled-14 (UC Berkeley) for the YC Fall 2026 RFS, *The Future of American Defense*.
Dual-use: airport drone safety, wildfire response.

**All data is simulated.**
